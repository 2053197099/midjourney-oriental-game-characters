# 东方题材与角色线索

以下是题材选择索引，不是每条提示词都必须装入的元素清单。先选角色身份，再选一两处可见线索；地点与奇观只用于理解身份与造型，不写入背景；概念角色采用单一背景。这里的分类有题材、时代文化和视觉风格，可以按用户要求组合，但要让组合后的身份与造型自洽。

## 选项分组

以下四组用于题材未定时的菜单，收录26个常用入口，并非支持范围上限。支持自定义东方题材、地域、地点与原创世界观的角色设计，允许跨组组合；用户已有方向或角色名单时直接设计，不要求归入菜单后再生成。

- **神话与高幻想**：山海经 / 上古异兽、古风修仙 / 仙侠、东方玄幻、西游神话、封神 / 商周神话、东方海洋神话。
- **志怪与民俗**：聊斋 / 中式志怪、中式克苏鲁 / 东方诡秘、民俗恐怖、中式妖怪 / 百妖夜行、地府 / 阴曹世界、苗疆 / 巫蛊幻想、傩文化 / 原始祭祀。
- **宗教、历史与审美**：敦煌 / 飞天仙境、佛教神话 / 东方神性、道教神话 / 道法世界、古蜀 / 三星堆幻想、水墨仙境、宋韵 / 东方生活美学、盛唐幻想、东方梦境 / 诗词幻想。
- **江湖与新幻想**：武侠 / 江湖、东方废土、赛博东方 / 赛博武侠、东方蒸汽朋克、东方机关术 / 墨家幻想。

地域与地点可作为角色设计来源，例如江南园林、岭南水乡、古寺、山寨或原创妖城。提炼其身份、服饰、物种与器物特征，不把地点画成背景场景。

## 题材与形体的区别

题材是世界观与文化方向，角色形体是身体结构，两者不互相限制。兽首、虫形、多足、翼肢、软体背壳、植物、器物、岩石或元素灵体均可按用户设定设计。CG、手绘等表现风格由用户另行指定，不随题材或形体自动添加。

保留用户给定的头部、肢体数量、连接方式与主要材质，不把所有异物改成美型人脸。美型需求只在用户明确要求或参考适用时启用。各方向仍采用全身构图、平视为主与单一背景。
