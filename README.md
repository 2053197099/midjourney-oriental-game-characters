# 东方游戏角色 Midjourney Skill

一个用于东方武侠、历史奇幻与神话游戏角色设计的 Codex Skill。它把角色身份、造型、装备、姿态和画面表现整理成可直接交给 Midjourney 的中英文提示词。

本项目只负责**角色提示词**，不负责场景环境提示词，也不会直接调用 Midjourney 生成图片。

## 能解决什么问题

角色提示词容易落入同一套模板：黑衣、长剑、冷脸、正面站姿，或靠堆叠配饰和特效来制造“东方感”。本 Skill 会先确定角色的可读身份，再选择少量符合职业的服装与装备，并用姿态、镜头、构图和定向光影强化角色特点。

适合用于：

- 设计一组职业、剪影和气质各异的东方游戏角色。
- 根据明确职业或人物方向，扩展多个角色造型方案。
- 把用户提供的文字或图像参考转成原创角色提示词。
- 调整已有提示词中的服装、武器、姿态、镜头或光影。

## 快速开始

在 Codex 中调用：

```text
使用 $midjourney-oriental-game-characters，给我 10 个不同职业的东方武侠游戏角色提示词，造型不要重复。
```

也可以直接指定角色方向：

```text
使用 $midjourney-oriental-game-characters，设计 5 个雪山守关人，分别尝试不同的年龄、体态、服装轮廓和武器。
```

```text
使用 $midjourney-oriental-game-characters，根据这张参考图提炼服装材质与轮廓语言，设计原创角色，不要复刻原角色。
```

默认每批生成 5–10 组，具体数量以用户指定为准。用户只要求一组不同角色时，直接设计有差异的类型；只有缺失信息会实质改变结果时才追问，不为常规偏好增加问答步骤。

## 默认输出格式

- 每组围绕一个角色，角色身份清晰，造型彼此有真实差异。
- 同时提供中文和英文提示词。
- 每条提示词用对应题材的短前缀开头，例如“东方武侠游戏角色设计”，英文提示词使用相应译法。
- 单人古风角色提示词默认在末尾排除其他人物、现代服饰、文字和水印；用户有不同要求时相应调整。
- 角色名写在代码块外；中文提示词合并在一个代码块，英文提示词合并在另一个代码块。
- 代码块内只放可复制的提示词，不放编号、说明或分析。
- 默认不写人物履历、剧情背景和无关道具；需要故事设定时由用户提出。

## 设计流程

1. 提取用户明确给出的角色类型、数量、题材、参考和限制。
2. 判断画面用于展示完整造型、人物表情，还是同一角色的系列图；为角色确定一个主辨识点和少量可见的身份依据。
3. 把抽象设定转成衣装、磨损、装备或习惯动作，再选能突出这些特征的景别与构图。
4. 用有方向的光线突出脸部、轮廓、手势或关键装备；背景只作衬托。
5. 检查身份、装备和服装是否合理，同批角色是否撞型，最后删掉多余细节。

## 提示词包含什么

按角色需要组织，不必机械填满所有项目：

> 题材前缀 → 身份与画面用途 → 一个主辨识点 → 可见的身份依据 → 姿态表情 → 景别构图 → 必要的光影背景与限制

角色辨识度主要来自剪影、体态、职业装备、材质和一两个核心特征。角色设计默认采用半身（腰部以上）或全身构图，以便看清衣装与装备；用户明确要求脸部、妆发或表情特写时再使用头肩近景。机位和构图可采用低机位、侧面、偏心或轮廓留白；光线要有明确落点，避免所有区域平均发亮。

## 如何描述需求

可以提供以下信息中的任意几项：

- **角色方向：** 游侠、镖师、药师、道士、僧人、机关匠、守关人等。
- **题材与时代：** 武侠、神话、历史奇幻、宗门、边镇、沙海等。
- **外形范围：** 年龄、性别、体态、气质、服装轮廓。
- **装备与动作：** 武器、工具、站姿、战斗姿态或安静动作。
- **画面要求：** 全身或半身、视角、构图、光线、背景繁简。
- **参考边界：** 想借鉴哪些造型原则，以及哪些元素不能复刻。

信息不完整但目标仍清楚时，Skill 会自行作合理选择并保持提示词简洁；不会为了显得丰富而添加一串无关饰物、特效或剧情道具。

## 使用参考图或游戏参考

参考图用于分析轮廓、材质、服装结构、姿态或光线关系。输出应形成原创角色，不照搬已有作品中的标志性服装、武器组合、面部特征或完整造型。用户若只想调整某一项，就只围绕该项修改。

## 安装

本仓库根目录就是一个 Codex Skill。配置好 GitHub SSH 后，可在尚未安装该 Skill 的电脑上克隆到 Codex Skills 目录：

```bash
git clone git@github.com:2053197099/midjourney-oriental-game-characters.git ~/.codex/skills/midjourney-oriental-game-characters
```

安装后在新的 Codex 任务中通过 `$midjourney-oriental-game-characters` 调用。若使用自定义 `CODEX_HOME`，请把仓库放入对应的 `skills` 目录。

## 项目文件

- `SKILL.md`：提示词生成流程、造型原则和输出自检。
- `agents/openai.yaml`：Codex 中的 Skill 名称、说明和默认调用语。

## 范围

- 面向原创的东方武侠、历史奇幻与神话游戏角色。
- 默认单角色画面；用户要求群像、三视图或角色设定表时再调整。
- 默认避免其他人物、现代服饰、文字和水印；限制词按具体画面取舍。
- 不用于纯场景、建筑、环境叙事或 Midjourney 图片生成执行。
